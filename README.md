# Resources

JSON name tables extracted from the global (GL, English) client. They are generated by [resource-extractor](https://github.com/dff-oo/resource-extractor); do not edit them by hand. Re-run `npm run extract` there to refresh them.

Each character's `image_id` names its head image, `characters/<image_id>.png` in the [cdn](https://github.com/dff-oo/cdn) repo.

The field editor installs this repository as `@dff-oo/resources`. Copy `data/` into the server's `resources/` when the server needs the names. That folder is git-ignored.
