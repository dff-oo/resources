# Resources

JSON name tables extracted from the global (GL, English) client. They are generated by [resource-extractor](https://github.com/dffoogg/resource-extractor); do not edit them by hand. Re-run `npm run extract` there to refresh them.

`data/characters/<image_id>.png` is each character's head from the client's event art, trimmed and at half size. `image_id` comes from `characters.json`. The art belongs to Square Enix.

The field editor installs this repository as `@dffoogg/resources`. Copy `data/` into the server's `resources/` when the server needs the names. That folder is git-ignored.
